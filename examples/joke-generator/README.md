Random Joke Generator example using icanhazdadjoke.com

This small example is included in the repository under:

  examples/joke-generator/

Files
- index.html — a minimal web UI
- styles.css — styling for the UI
- script.js — fetches jokes from https://icanhazdadjoke.com/
- joke-cli.js — Node.js CLI example (Node 18+)

How to run (web)
1. cd examples/joke-generator
2. Open index.html in your browser (double-click or serve with a static server)

How to run (Node CLI)
1. node examples/joke-generator/joke-cli.js

Notes
- API used: https://icanhazdadjoke.com/ (no API key required for casual use). Respect rate limits for production.
