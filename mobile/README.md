# Tawaasol Mobile (Jokes) - Scaffold

This folder contains a minimal Android app scaffold that demonstrates integrating the random joke generator into an Android app using Jetpack Compose.

How to open
1. Clone the repo and open `mobile` in Android Studio (use the Gradle wrapper or install Gradle 7.4+).
2. Let Android Studio sync the project and download dependencies.
3. Run the `app` module on an emulator or device.

Notes
- The example uses OkHttp to fetch JSON from `https://icanhazdadjoke.com/`.
- Internet permission is granted in the manifest.
- If you need a fully reproducible Gradle wrapper, I can add it on request.
